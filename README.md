# ESCALA-BRISTOL

Herramienta médica que clasifica la forma y consistencia de las heces.

## Ejecutar la página

1. Descarga o clona este repositorio.
2. Abre `index.html` en tu navegador.
3. También puedes servirlo localmente con un servidor estático si prefieres:

```bash
python -m http.server 8000
```

Luego abre `http://localhost:8000`.
